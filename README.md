# Aprendendo C

My solutions to the C programming exercises from FACOM – UFU (Universidade Federal de Uberlândia).

The exercise list is available [here](https://www.facom.ufu.br/~backes/gci007/ListaC01.pdf).

## How to compile and run

Each exercise is a single `.c` file. To compile and run one:

```
gcc -Wall -Wextra -o program 01_inteiro.c
./program
```
